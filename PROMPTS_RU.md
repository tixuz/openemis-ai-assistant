# Документация разработки AI-Ассистента для OpenEMIS

Этот проект демонстрирует создание автономного агента, способного взаимодействовать со сложными ERP-системами (на примере OpenEMIS) через браузер.

### Этап 1: Архитектура системы (Boilerplate)
**Задача:** Создать связку Backend (FastAPI) и Frontend (Chrome Extension) для управления интерфейсом в реальном времени.

**Использованный промпт:**
> "У меня проект на Python 3.13 в PyCharm. Мне нужен шаблон для расширения Chrome + бэкенд FastAPI. Подготовь код для: 
> 1. main.py: сервер с эндпоинтом /chat. 
> 2. manifest.json: конфиг расширения V3. 
> 3. content.js: скрипт для инъекции кнопки 'AI' на страницы, который отправляет запросы на localhost:8000."

### Этап 2: Настройка инфраструктуры и Git
**Задача:** Настройка безопасного деплоя и версионности.

**Использованный промпт:**
> "Помоги настроить SSH-ключи Ed25519 для связи iMac с GitHub, исправь ошибку ветки master/main и подготовь requirements.txt для Python 3.13."
